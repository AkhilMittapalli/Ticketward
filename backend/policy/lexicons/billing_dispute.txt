# lexicon: billing_dispute
# version: billing_dispute.v1
# purpose: chargebacks and payment disputes with a bank or card issuer ("dispute with my bank",
#   "reverse the charge") for rule P5. Recall first: the model intents billing_duplicate_charge
#   and billing_payment_failure (primary or secondary) are OR-ed with this lexicon.
# consumer: P6 policy engine rule P5 (terminal: human_escalation, reason
#   forced_category_payment_dispute, tpl_holding_billing; a lexicon-only hit routes to
#   billing_and_accounts, spec §7.3.2); E1 rules baseline (ml/src/tw_ml/baselines/rules.py).
# groups: chargeback (a chargeback or formal dispute), bank_dispute (disputing or reversing a
#   charge with the bank or card issuer, fraudulent-charge claims).
# matching: case-folded, NFKC-normalized, invisible characters stripped. Applied to the sanitized,
#   PII-masked customer text (subject, latest message and customer-authored prior messages).
#   Normalization, in order: remove Unicode format characters (category Cf: zero-width
#   characters, bidi controls, BOM, soft hyphen, tag characters U+E0000-U+E007F) and variation
#   selectors (U+FE00-U+FE0F, U+E0100-U+E01EF); NFKC; case-fold; NFKC again; fold typographic
#   apostrophes (U+2018, U+2019, U+201B, U+02BC, U+2032) to '; collapse whitespace to one space.
#   Homoglyphs are not folded. A pattern fires when it matches anywhere in the text; the evidence
#   is the pattern id <lexicon>.<group>.<8 hex hash of the pattern>, never the matched text.
#   "charge back" as two words is matched only after a filing verb (time tracking "charges
#   back" hours to clients).
# syntax: [group] opens a group. A plain line is a whole-word phrase: its words match in order,
#   separated by any whitespace, with no word character directly before the first or after the
#   last word; a trailing * on a word matches any further word characters. A line starting with
#   re: is a Python regular expression (IGNORECASE) on the normalized text, written in lower case
#   with ' as the only apostrophe. Lines starting with # are comments; blank lines are ignored;
#   duplicate patterns and empty groups are errors (reference parser: tw_ml.baselines.lexicon).
# changes: any edit bumps the version; versions enter policy_rule_sets.lexicon_versions and so
#   policy_version (spec §7.3.3). Every group keeps >= 3 positive and >= 3 negative unit-test
#   examples (ml/tests/test_lexicons.py; P6 adds the engine's own table tests).

# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1**:
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>. The full text at that
link is the authoritative version and is incorporated here by reference.

## Summary

- **Pledge:** everyone can take part without harassment, whatever their identity,
  background or experience level.
- **Expected:** kindness, respect for other viewpoints, constructive feedback given and
  received well, owning mistakes, and putting the community first.
- **Not acceptable:** harassment of any kind, insults or personal attacks, sexualized
  content, trolling, and sharing someone's private information without consent.
- **Scope:** all project spaces (issues, pull requests, discussions, reviews) and public
  spaces where someone officially represents the project.
- **Enforcement:** the maintainer reviews every report promptly and fairly, respects the
  reporter's privacy, and may apply the Covenant's enforcement ladder: correction,
  warning, temporary ban, permanent ban.

## Reporting

Report conduct concerns privately to the project maintainer. Until a dedicated contact
address is published (planned before the public release, P11), use the maintainer's
contact details on their GitHub profile; do not use public issues for conduct reports.
Security vulnerabilities follow [SECURITY.md](SECURITY.md) instead.

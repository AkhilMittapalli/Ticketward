# Acceptable Use Policy

## 1. Purpose

This Acceptable Use Policy (AUP) defines the rules governing acceptable conduct and usage of the Taskmoor platform. All users, workspace administrators, and API consumers are required to comply with this policy. Violations may result in account suspension or termination.

## 2. Prohibited Uses

Customers may not use the Taskmoor platform to:

- Store, transmit, or distribute content that is unlawful, defamatory, obscene, or that violates the intellectual property rights of others.
- Engage in or facilitate fraudulent activity, money laundering, or any activity that violates applicable laws or regulations.
- Harass, threaten, or abuse other users, Taskmoor employees, or third parties.
- Distribute malware, viruses, or other harmful code through attachments, integrations, or API endpoints.
- Attempt to gain unauthorized access to Taskmoor systems, other customer workspaces, or third-party systems through the Taskmoor platform.
- Circumvent or disable security controls, access restrictions, or usage limits implemented by Taskmoor.
- Scrape, mine, or systematically extract data from the Taskmoor platform except through documented APIs and within applicable rate limits.
- Use the platform for cryptocurrency mining, large-scale media hosting, or purposes unrelated to project management and team collaboration.

## 3. API Usage and Rate Limits

API access is subject to rate limits that vary by plan tier. Customers must not:

- Exceed the published API rate limits for their plan. Current limits are documented in the Taskmoor API Reference.
- Use automated tools or scripts that generate excessive API traffic with the intent to degrade service performance.
- Share API keys or tokens with unauthorized third parties.
- Use the API to build a competing product or service that replicates substantial Taskmoor functionality.

Customers who anticipate temporarily exceeding rate limits for legitimate use cases (such as data migrations) should contact support in advance to arrange temporary limit adjustments.

## 4. Automation Limits

Automations (workflow rules, triggers, and scheduled actions) are subject to per-plan monthly run limits. Customers must not design automations that:

- Create infinite loops or recursive triggers that consume automation runs without productive output.
- Deliberately exhaust automation quotas to disrupt workspace functionality.
- Send unsolicited bulk messages, notifications, or emails to users outside the customer's organization.

## 5. Resource Consumption

Taskmoor reserves the right to throttle or suspend accounts that consume disproportionate platform resources in a manner that degrades the experience for other customers. This includes excessive storage consumption beyond plan limits, sustained high-volume API activity, or abuse of real-time collaboration features.

## 6. Enforcement

Upon identifying a potential violation, Taskmoor will:

1. Notify the workspace administrator by email with details of the suspected violation.
2. Allow a reasonable period (typically 48 hours) for the customer to remediate the issue, except in cases where immediate action is necessary to protect the platform or other customers.
3. Suspend access to the affected workspace or API key if the violation is not remediated or if the violation is severe.
4. Terminate the account for repeated or egregious violations, in accordance with the Terms of Service.

## 7. Reporting Violations

Users who observe violations of this policy may report them to abuse@taskmoor.com. Reports are treated confidentially and investigated by the Taskmoor Trust and Safety team.
